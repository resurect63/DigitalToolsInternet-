Frequently Asked Questions

Is VORTEX VPN fully available?

Not yet. The VPN service is under development.

Does the power button connect me to a VPN?

No. It only changes the visual demo state. It does not connect to a server.

When will the VPN be ready?

The service is being developed. Updates will be announced when real server connectivity is available.

What does the DNS tool do?

It queries public DNS records for a domain. It does not change your device's DNS configuration.
